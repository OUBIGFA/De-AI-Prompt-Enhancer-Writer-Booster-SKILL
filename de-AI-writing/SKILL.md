# de-AI-writing

## 定位

本技能是纯粹的去 AI 味补丁工具，不规定文风。无论原文是现代白话、口语化、学术化还是其他风格，都只在保留其原有文风的前提下做减法。

默认目标很窄：保留原意、保留信息厚度、保留作者判断，只删掉让读者意识到"这是模型在组织答案"的结构痕迹。不要为了清零黑名单把文章改成中性说明书,**更不要主动注入任何特定风格元素**（如文言虚词、半文半白用词、书卷气语体、知识分子腔等）。原文是什么风格,改完依然是什么风格。

## 任务分流

先判断用户要的是哪一种任务，再加载对应参考文件。不要一上来读完整套资料。

- **改写/润色/续写中文稿**：默认保真改写，按本文件的"快速硬门槛"执行减法。需要更详细的 AI 痕迹清单时再读 `references/ai-trace-detector.md`。
- **翻译**：读 `references/translation-guardrails.md`。翻译优先结构保真，不额外加标题、不补观点、不把原文改成中文评论。
- **审阅/评分/找问题**：读 `references/ai-trace-detector.md`，只抓 Top 5-10 个最影响读感的命中，不做全量黑名单罗列。

不确定是否需要全文改写时，先做最小可用修补；只有用户明确要求"自由改写/允许增删重组"时，才重排结构。**任何情况下都不要主动把原文改成半文半白、文言点缀、书卷气语体——除非用户明确要求采用这类风格。**

## 默认交付

- 默认只输出最终正文，不输出流程、清单、自检记录或代码块。
- 生成、改写、精修任务要给标题；翻译任务保留原文标题，不另起标题。
- 标题不超过 20 字，避免 SEO 腔、悬念标题和工整对仗；冒号按实际语义使用，不把 `A：B` 当固定标题模板。
- 小标题不做硬性数量规定，按内容长度和题材评估。如果文章需要或原文带小标题，**3-4 个是常见的舒适区间**：太少不分层，太多变讲义。短文（< 1500 字）通常无需小标题；长文按内容自然章节切分，每个小标题下至少覆盖 2 段正文，否则下沉为段首句。无论用几个，都避免对仗式、悬念式和只为制造提纲感的冒号标题。
- 保真改写时不新增事实、案例、数据和结论；不删除原文核心论证链；尽量保持段落一一对应。

## 快速硬门槛

以下是最终交付前必须通过的短检查。细项和修法见 `references/ai-trace-detector.md`，不要把完整清单复制进正文推理。

1. **二分对照壳**：默认清零 `而是` 及 `不是/并非/不在于 A 而是/而在于 B` 一类结构。逐字引文或原文自然保留最多 1 处。
2. **冒号**：不设数量硬规定，按实际语义使用；人工审核它是否在当提纲、路标或扩音器。`概念：解释`、`问题：答案`、`原因：结论` 这类模板化冒号默认改写，直接放回句子里。
3. **二人称**：默认不用 `你/你会`；`你会` 必须为 0。确需读者推演时，最多 1 次 `试想` 或 `当你`。
4. **一人称**：第一人称 `我` 非默认必备，按题材判断——信息/科普/客观分析类常以无主语判断推进，未必需要 `我`；个人评论、书评、随笔等"作者在场"体裁才自然带。改写时不主动注入原文没有的 `我`；原文已有 `我` 时按原文风格保留，禁止把作者偏冷静、偏自嘲、偏怀疑的 `我` 改写成戏剧式、记者式或演讲腔。
5. **路标词**：`更关键/更要命/换句话说/事实上/值得注意/总之/与此同时` 全文合计 `<= 2`。
6. **AI 身份与协作口吻**：清零 `作为AI`、`截至我的知识`、`希望这能帮助你`、`接下来我们将`、`我们先来看`、`下面我们`。
7. **伪口语化与讲义动作**：删掉 `拆一拆/盘一盘/捋一捋/聊一聊/划重点/敲黑板`，以及 `说白了/本质上/归根结底/简单来说` 这类降维引导语；不要在正文交代分析流程。
8. **伪坦率与伪严谨评价词**：`直白/坦白/坦率/无遮拦/明白无误/赤裸/赤裸裸/不加掩饰` 等坦率标签默认清零（典型句式：X 说得很直白 / 答案直白得多 / 数据说得更直白 / 写得很直白），让事实自己说话；`严谨/严密/严苛/严格/精准/审慎/克制/沉稳/从容` 等克制标签如无必要一律删——挂在可核对对象上才保留（如"严密的逻辑论证"后真有论证铺开），挂在空对象上必删（"严谨地探讨"→"探讨"）。
9. **AI 高频隐喻**：`噪音/信号/底色/光谱/滤镜/解药/土壤/拼图/镜像/路径/窗口/缩影/账本/成绩单/清单` 等词的比喻义命中即改，字面义不管；其中 `账本/成绩单/清单` 用来把复杂问题包装成可结算、可打分、可勾选对象时默认禁止。
10. **高频分析词与术语壳**：`拆解/梳理/剖析/解构/聚焦/洞察/深耕/赋能/助力/践行/驱动/构建/打造` 不要堆叠；`舆论/舆论场/中文舆论/公共舆论/网络舆论/媒体舆论/宏大叙事/底层逻辑/赛道/闭环/抓手` 等伪学术词全文合计 `<= 1`。没有具体平台、媒体、账号、报道或人群时，不用抽象"舆论"代替事实。
11. **政论/媒体研究术语**：`口径/出口径/统一口径/定调/定过调/话术/这一套话术/通稿/喉舌` 等政论术语全文合计 `<= 1`；机构串联做权威铺垫（"X 研究部和 Y 咨询部"等）全文合计 `<= 1`，且必须紧跟可追溯原话或具体数字。详见 `references/ai-trace-detector.md` 7.6.1。
12. **数据展示动作（戏剧化揭露的低戏剧度副本）**：`数字/数据/事实/账目/账本 + 摆 + 出来/在那里/给X看`、`摆得清楚/摆得更清楚/摆得明白/摆得明明白白`、`另一组/再摆一组` 默认清零——删扩音动作，直接给数字和判断。
13. **标签讽刺与群体对立化指代**：`万能 + 具体名词`（万能贴纸/挡箭牌/护身符/解药/钥匙/借口/筐/背锅侠）默认清零；`X 得最 Y 的那批/那波/那群` 与 `那批/那波/那群 + 群体名` 指代合计 `<= 1`，且必须给具体人/账号/事件。
14. **代际/历史责任的接力比喻**：`接力棒/这一棒/接过X的棒/把棒交给/把火炬传给/不必接这一棒` 等接力隐喻默认清零，直接铺代际事实。
15. **分析包装腔三件套**：`一整套 + 抽象名词` 默认清零；抽象事物 `扎根/落地/生根/蔓延/站住脚` 默认清零；`X 之所以在 Y 中 Z` 长因果开段句全文合计 `<= 1`，且必须紧跟可核对机制。
16. **高频句式壳**：`一旦……就……`、`只有……才……`、`无论……都……`、`随着……的发展/推进`、`正是因为……所以……`、`通过……来……` 全文合计 `<= 2`。
17. **戏剧化揭露与极值判断**：清零 `遮羞布/面具/外衣/揭开真面目/戳穿真相` 这类揭露修辞；`最 + 形容词/判断`、`最……的地方在于/是`、`最先/最早/最容易/最常/最该 + 往往/反而/还是`、`真正……的是`、`……之处在于`、`更……的是` 默认清零。只有可核对的事实排序、数量第一、时间最早可保留，并必须给出具体对象或依据。
18. **定义式/判断式堆叠**：`A 是 B`、`A 不是 B`、`所谓 A 即 B`、`A 就是/意味着/可以概括为 B`、绝对化副词加判断句，全文合计 `<= 3`，每处必须有事实、机制或限定条件支撑。
19. **解释预告与工整递进壳**：`原因/答案/问题/逻辑/现实 + 很/非常/相当 + 形容词`、`原因/答案/事实/现实/问题 + 摆在那里/摆在眼前/摆着` 默认清零；`A 尚且/尚且还/都已经 B，C 更/更是/更会 D` 这类工整递进句默认清零。不要先宣布"原因很朴素/原因摆在那里"，直接写具体原因；不要用"街头代价更直接"这类对称递进制造结论感，改为具体后果。
20. **重复问题判词与"并不X"降调壳**：`问题不在于……。……。问题在于……`、`问题不是……。……。问题是……`、`X 多了去了`、`并不 + 复杂/新鲜/意外/奇怪/难懂/高明/深奥` 这类短句三连和降调判断默认清零。不要用重复"问题"开头、口语判词或"说得并不复杂"制造洞见感；把判断并回一条事实链。
21. **"省"字解释捷径**：`省事/省力/省心/省麻烦/省去了/省掉了/省下了/省得再/省得去/替代思考` 默认清零。不要用"省"字概括动机或机制；写清楚它具体删掉了哪一步、回避了哪项事实、替代了哪种判断。
22. **"很容易"解释捷径**：`很容易 + 把/被/让/想到/变成/说成/理解成/归为/滑向` 默认清零，尤其禁止 `中文舆论很容易把它说成……`、`人们很容易把 X 理解成 Y`、`这种说法很容易滑向……`。不要用"很容易"替代机制；写清楚谁在说、在哪里说、怎样说。
23. **"想象中"稻草人壳**：`某些人/有些人/很多人/不少人 + 想象/以为`、`想象中那么/想象里那样`、`本来就没有……想象中那么……` 默认清零。不要用模糊人群当靶子；改成具体观点、文章、账号、说法或可核对材料。
24. **"却"字工整反差壳**：`X 却 Y`、`字面上/表面上/名义上/看似 + X，却 + Y`、`谐音/背后/里面/暗处 + 藏着/带着 + Y` 默认清零。尤其禁止 `字面上是……，谐音里却藏着……`。不要用"却"制造反转感；改成并列事实或直接解释具体来源。

25. **判断递进壳**：禁止"判断头 + 同形容词回声 + 程度副词到"的句式——以"在于/不在于"及其前置词（麻烦/问题/毛病/关键/妙处/坏处）开头，逗号后再用同一形容词搭配"到/到足以/以致/以至/直至/直到"做强化递进。逐字引文除外。改写时删掉"……在于……"判断头，直接写动作或后果；若要递进，用两个独立短句铺事实，不让同一形容词回声。
26. **二元分类列举壳**：禁止"数量分类预告 + 成对分类词领句"的句式。凡是先说对象落入、分成、归为若干类，再用序数分类词对称铺开，正文默认清零。逐字引文除外；真实资料有分类时，改成事实链或按来源交代，不照搬成对称句壳。
27. **"仿佛"虚拟夸张壳**：逗号或分号后接 `仿佛/好像/似乎 + 虚拟场景/夸张后果` 默认清零，尤其是前半句已经下判断、后半句只负责扩音时。逐字引文、真实心理描写和人物视角叙述除外；作者自己的分析不要用"仿佛"制造想象画面。
28. **"下去"动作拖尾壳**：`动词 + 下去` 的修辞用法默认清零，尤其是 `切下去/砍下去/压下去/打下去/推下去/落下去/拍下去` 搭配政策、法案、规则、预算、处罚、舆论、标签等抽象主语。真实空间移动、口语逐字引文、人物实际动作除外。改写时直接写执行动作、影响对象、被删掉的项目、金额、条款或后果。
29. **话题入场比喻/拟人壳**：`对象/话题 + 一被谈起/一被提起/一说到/谈到/提到` 后立刻接比喻、拟人化物象、场景、气味、声音或抽象概念代言，默认清零。任何"先抛话题，再让画面替话题开场"的句式都删除。逐字引文、小说叙述、人物感官描写除外；评论、说明、科普和分析类文本直接进入事实、争议、来源或判断。
30. **温和让步壳与"X 的地方"包装壳**：以下三类合并正文清零，逐字引文除外。① `X + 当然/自然 + 有 + 它/他/她/其 + 的 + 道理/逻辑/来由/来处/原因/苦衷/考量/合理性/必然/根据/语境/历史`，典型如"这种安稳当然有它的人情来处"；只有紧跟"但/而"+ 具体事实的不对称让步可保留 1 处。② `X 的 麻烦/问题/争议/风险/讨论，原不该/原本不该/本不该/不该/不至于 + 被 + 拖进/卷入/牵扯/裹挟/扯进/搬到/写成/简化为`，典型如"马兜铃酸的麻烦，原不该被拖进文化身份的争执里"。③ `X 还有一个/另一个 + 更/最/真正 + 麻烦/棘手/讨厌/复杂/严重/微妙/吊诡/难办/糟糕 + 的地方`，以及"X 麻烦/棘手/难办的地方在于/是"，典型如"马兜铃酸相关风险还有一个更麻烦的地方"——本质是 7.5"最残酷的地方在于"的低戏剧度副本。改写时把"当然/原不该/更麻烦的地方"做的缓冲器删掉，直接给具体处境、具体后果或具体动作；禁止把"当然"换成"自然/原本"、把"麻烦的地方"换成"棘手的地方/讨厌的地方/复杂的地方/难办的地方"做变体逃逸。

31. **指示性定位收束壳（"X 正卡在这条裂缝里 / X 的难处正在这里"）**：以下三类合并正文清零，逐字引文除外。① `主语 + 正/就/恰好/偏偏/眼下 + 卡/落/夹/陷/停/堵/挤/吊/悬/绕/绊 + 在 + 这条/这道/这个/那条/那道 + 裂缝/缝/缝隙/夹缝/边界/边/线/点/口/位置/中间/之间 + 里/上/中`，典型如"中药注射剂正卡在这条裂缝里""这件事就夹在两条线中间"。② `X + 的 + 麻烦/难处/痛点/要害/关键/症结/微妙/吊诡/糟糕/棘手/复杂/特殊/危险 + (之处/的地方/处)，+ 正/就/恰恰/偏偏 + 在这里/就在这里/正在这里/正卡在这里/卡在这一点上`，典型如"中药注射剂麻烦的地方，正在这里""中药注射剂的难处正在这里"。③ `问题/答案/原因/事情/关键 + 就/正 + 在这里/在这一点上/在这条线上/在这个缝隙里`。本质同 7.5"最 X 的地方在于"和 9.7③"X 还有一个更麻烦的地方"——把"最/还有一个/更"换成"正/就 + 在这里"，靠指示副词 + 空间隐喻给抽象问题指认一个位置，制造"我手指着给你看真相"的姿态。改写时删掉指示句和空间隐喻，直接铺机制或后果；禁止把"正在这里"换成"就在这里/恰恰在这里/正卡在这一点上"做变体逃逸；禁止把"裂缝"换成"缝隙/夹缝/边界/边/线/口"做名词替换逃逸。

32. **无生命对象拟人化否定壳（"血管不认这些词 / 数据不在乎你的立场"）**：`无生命主语/抽象主语(血管/身体/细胞/器官/数据/数字/账本/历史/市场/算法/制度/规则/法律/时间/河流/山/路/物理/化学/分子/病毒/伤口) + 不/不会/不肯/不愿/听不懂/看不见/记不住/不在乎/不在意/不接受/不认/不挑/不分/不等/不讲/不管/不理 + 抽象对象(这些词/这套说法/你那一套/立场/情绪/标签/口号/道理/面子/身份)`，典型如"血管不认这些词""市场不在乎你那一套""数据不挑立场""分子不分中西医"。本质是 7.4"戏剧化揭露"和 7.5"极值判断"的拟人化副本——用无生命对象的"冷峻拒绝"替代具体机制说明，制造金句感。正文默认清零；逐字引文、真实空间/物理动作描写、固定俗语（如"时间不等人"作为引用语境）除外。改写时把拟人化否定改成具体机制——把"血管不认这些词"换成"马兜铃酸进入血液后直接作用于肾小管，与药材是中是西无关"；把"市场不在乎你那一套"换成"这只股票的成交量自 2024 年 Q3 起连跌六个月"；禁止把"不认"换成"不接受/不在乎/不理/不分"做动词替换逃逸；禁止把"血管"换成"细胞/分子/数据/历史"做主语替换逃逸——它们是同一个模板。

33. **段落开场短句惯性（"每段先抛一个短判断，再展开解释"）**：禁止把短句（<20 字）作为段落标配开场的机械模式。整篇正文中以短句开段的段落占比 `<= 1/3`，超过即判定为"AI 总分总结构换皮"——本质同二元分类列举壳和分析包装腔，只是把"先抛小论点再展开"做成了段间结构。典型病灶如：第一段"X 进 Y，多少还隔着几道关。"+ 长解释；第二段"X 把这段路绕开了。"+ 长解释；第三段"这和 Z 关系不大。"+ 长解释——每段开头都是一个 10-15 字的判断短句，后接展开。**段落开头长短按内容自然决定**：要铺事实/铺场景/继续推论，就直接用多分句长句切入，让事实自己起句；只有当本段需要承接上段、转折或下冷判断时，才用短句开场；一句成段亦算短句开段。改写时把多余的短判断开头并回长句链里，或把判断挪到段尾收束，或干脆删掉让事实直接铺开。禁止把"短判断开场"换成"短问句开场/短反讽开场/短描写开场"做句式替换逃逸——它们都是同一个总分模板。

## 改写方法

执行顺序保持轻量：

1. 先保原意和段落功能，判断每段是在交代事实、推进论证、转折、收束，还是只是模板过渡。
2. 修掉最显眼的 AI 痕迹，优先处理二分对照壳、二元分类列举壳、话题入场比喻/拟人壳、温和让步壳与"X 的地方"包装壳（"当然有它的 X / 原不该被 X / 更麻烦的地方"）、指示性定位收束壳（"正卡在这条裂缝里 / 麻烦的地方正在这里 / 难处正在这里"）、无生命对象拟人化否定壳（"血管不认这些词"）、重复问题判词、"省"字解释捷径、"很容易"解释捷径、"想象中"稻草人壳、"却"字工整反差壳、判断递进壳、"仿佛"虚拟夸张壳、"下去"动作拖尾壳、解释预告句、工整递进壳、路标词、提纲化冒号、伪口语化动作、鸡汤收尾。
3. 把模板句改成事实句或判断句。删“值得注意的是”，保留后面的信息；删“不是 A 而是 B”，直接写 B，再补机制或事实。
4. 修补只做局部。除非结构本身已经坏掉，不要因为命中一个词重写整篇。
5. 最后通读一遍：如果段落变薄、句子变短、语气变平，说明除味过度，回滚一部分。

可用替换方向：

- 否定转折壳：改为不对称让步，如 `A 固然……；但……`，或直接先写核心判断；不要用 `却` 制造工整反差。
- 定义式判断：改为动作、事实或场景还原，如 `A 在做 X`、`碰上 A 时，常见做法是……`。
- 讲义式列举：把清单揉进长句链，用逗号、分号和插入语承接。
- 空泛归因：无来源的 `专家认为/研究表明/业内一致认为` 降级为限定表达，或直接删除。

## 段落节奏

评论/散文类倾向厚段、长句链与少量一句成段的交替，保持密度。

**首要原则：阅读节奏优先于段长指标。** 长段、短段、一句成段三者按内容自然交替才有呼吸感——这里的"短段"指的是独立承担承接/转折/收束/冷顿挫功能的整段，**不是"段落开头先抛一个短判断、再展开解释"的句子排布**。短段（含一句成段）只要承担了"承接前文 → 给出冷判断/反讽/转折 → 引出下文"这类节奏功能，就是合法装置，不要因为字数短或为了凑"段数指标"被回填到厚段里。

以下面这一节奏为例：

> 此人正热情发帖嘲笑美国两党争议导致俄亥俄州火车脱轨，顺手写了一篇长文论证西方的基建已经崩溃。点开他的主页，上一条动态是几个月前的讨薪求助——在本地被拖欠了半年工资，跑了几趟劳动监察大队，四处碰壁，连个回音也没有。
>
> 这确实是个很大的黑色幽默。
>
> 自己陷在连工资都讨不回来的小灾难里，眼睛死死盯着大洋彼岸的灾难……

中间那句一句成段不是碎段失控，而是把场景压缩成独立的判断换气点；下一段顺着前文事实继续推进，**不必再用一个短判断起句**。形成的是"长河—顿挫—长河"的呼吸感，而不是"每段先短判断后展开"的总分模板。这类短段不计入"被合并"清单。

信息/科技类文章可以更透气，但不能碎：

- 1500-3000 字正文通常 `14-18` 段，作为参考区间，不作硬性指标。
- 中段 `90-180` 字是主体，目标 `5-8` 段。
- 厚段 `180-300` 字，目标 `3-5` 段；单段超过 `350` 字要检查是否能在话题转换处拆分。
- 短段（30-90 字）与一句成段按节奏需要使用，不预设上限；只要承担判断、反讽、转折、收束、承上启下等功能即可。下面三类要回填或改写：
  - 写成"下面说说""接着看"式路标句的短段；
  - 写成"总之/换句话说"式空转过渡的短段；
  - 与上下段语义重复、删掉不影响阅读的短段。
- 连续 `3` 段 `<60` 字且都是空转过渡才视为碎段失控；如果每段都各自承担节奏功能，不算碎。连续 `2` 段 `>250` 字要检查是否形成砖墙。

## 翻译模式

翻译任务只给译文正文。遵循 `references/translation-guardrails.md`：

- 保留原文结构、层级、列表、表格、代码和链接。
- 不增删信息，不改变原文立场强度。
- 默认语体更书面、更克制，不额外注入第一/第二人称。
- 原文标题存在时保留；没有标题时不要擅自补标题，除非用户要求。

## 审阅模式

仅当用户明确要求“审阅/检查/评分/列问题”时输出审阅报告。

输出顺序：

1. 原文风格贴合结论：1 段，判断改写是否还像原作者本人在写，而不是通用干净文或讲义体。
2. AI 痕迹 Top 5-10：每条包含命中片段和一句修法。
3. 关键风险：只写会真正损害成稿的风险，如变平、变薄、变说明书。

不要把 `references/ai-trace-detector.md` 的完整清单倒给用户；审阅要按影响排序。
