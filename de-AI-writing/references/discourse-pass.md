# 篇章层（discourse-pass）—— 段落如何推进、能量在哪里塌、东西放在页面的什么位置

第一层检查，最先读（叙事类文本先读 `narrative-pass.md`，再读本文件）。本层抓的是**句子以上、情节以下**的那层：每段在回答什么问题、段落长短和功能是否均匀、中段有没有塌、引语和强调放在哪里。研究测得这一层的痕迹比词句层顽固得多——把词汇句式全改掉，位置指纹反而更显眼；反过来，改掉一个问题序列、放进一段对比或质疑，比改一页词更有效。

> 阈值说明：本文各条里的"密度阈值 / 正文清零 / 全文 <= N"是识别强度标记，不是删除配额。按 SKILL.md 的校准原则执行：单次出现且读感自然的不算问题，成簇、连段、或明显在替读者宣布结论时才修；修完的文本要落在人类写作的常见区间，不是 AI 的反面。逐字引文、对话、原文本来的习惯一律不动。

### D1) 大纲测试（新增）

把每一段的第一句抽出来，按顺序连读。

- **信号**：这些首句连起来就是一份干净的全文摘要——每段第一句都是该段的论点，段与段之间承接平顺，没有一句脱离上下文看不懂。这是提纲扩写出来的形状：先有大纲，再往每个条目下面填肉。
- **人类区间**：人写的文章首句连读会有跳跃、断口、突然出现的具体细节、承接不上的句子；有些段第一句是事实、场景或引语而不是论点，论点藏在段中或段尾。
- **修法**：不要逐段换首句——那只是把论点换个说法。改变**信息进入段落的方式**：至少两三段改成从事实、场景、引语、数字、一个具体的人进入，论点后到；允许一段的首句在上一段的中间就已经埋好。

### D2) 每段回答什么问题（新增）

每一段都在隐含地回答一个问题。逐段写下那个问题，看序列。

- **信号（线性访谈）**：问题序列是"发生了什么 → 为什么 → 结果如何 → 这意味着什么"，每个问题都从上一个问题"行政性地"推出来。两个不同的模型拿同一个题目会独立生成同一串问题——换词不会改变这个序列，只有重排或替换才会。
- **信号（反思尾巴）**：最后一两段都在回答"这意味着什么 / 现在怎么看待它"。这是模型的收尾动作。
- **信号（缺少的动作类型）**：全文没有一段在**比较**（两个时间、两个人、同一件事的两个版本），没有一段在**质疑**（怀疑或推翻前面某段的说法），没有一段在**岔开**（一段回忆或联想，后面才看出用处）。模型写"后果/步骤"类段落的比例约是"比较/质疑"类的几十倍。
- **修法**：让至少一个问题先于它的铺垫出现；把一段"后果"换成一段"比较"或"质疑前文"——一句"但她姐姐记得的不是这样"式的段落，比一页改词更去 AI 味。评论文里对应的是：一段承认对方说法里站得住的部分、一段拿另一个案例对照、一段回头推翻自己前面的一个判断。

### D3) 中段是塌陷点（新增）

检测器和人类读者都在**正文中段**最容易认出 AI——开头和结尾模仿得最像，长中段暴露得最多。模型在中段会塌成可预测的填充：节奏加速、该展开的地方一笔带过、每段质地相同。这是在新闻、评论、邮件上都测到的，不只是小说。

- **修法（针对中间三分之一）**：放进至少一件开头预测不到的东西（一个反例、一段引文、一个数字、一个转向）；相邻段落质地要变——密的后面跟快的，事实堆叠后面跟一段判断，叙述后面跟一段引语；让一条线索慢下来而不是按计划解决——模型的失败模式是加速冲过最有意思的地方。

### D4) 位置指纹（新增）

位置模式比词语更能挺过改写：全文改写之后，位置指纹在专家读者眼里反而更显眼。

| 位置 | 机器习惯 | 人类习惯 |
|---|---|---|
| 段落长度 | 均匀 | 参差，包括一句成段 |
| 引语 / 关键句 | 总在段尾收束 | 任何位置，包括段中 |
| 列举（性质、理由、意象） | 恰好三项 | 两项、四项、一项，偶尔三项 |
| 段落过渡 | 每次同一种连接公式 | 硬切、时间跳跃、从对话接起、直接给事实 |
| 强调 | 均匀分布 | 集中在要紧处，其他地方没有 |
| 判断句 | 每段一句，位置固定 | 有的段两句，有的段没有 |

- **修法**：对着表逐项看全文，只改"整篇都一样"的那一项，不必每项都动。列举改成两项或四项；把一两处段尾引语挪到段中；把一段的过渡换成硬切。

### D5) 段落同构、等厚与段尾收束（新增，并入原硬门槛）

- **信号（同构）**：连续 3 段以上都是"观点句 + 解释 + 段尾总结"的三件套。修法是改变信息进入段落的方式（见 D1），不是替换段首词。
- **信号（等厚）**：每段长度、句数、功能都接近。人类区间是短段、中段、厚段按阅读节奏交替；评论、散文、书评厚段偏多，科普和综述可稍松。
- **信号（段尾收束）**：每段末尾都补一句抽象结论。能停在事实、场景、引语、具体后果上，就不要再概括。
- **信号（碎段）**：段落被切成一观点一段的均匀薄片；连续几段短段，或连续多段一句成段。碎段比任何"词汇"都更像 AI。反过来，连续三段厚段也会形成砖墙效应。
- **注意区分**"碎段"和"节奏短段"：承担承接判断、反讽、转折、收束功能的短段（含一句成段，如"这确实是个很大的黑色幽默。"）是合法的节奏装置，不要回填。只清那些"下面说说/接着看/总之"式路标短段和与上下段语义重复的空转短段。
- **修法**：先处理段落，再处理句子。合并无效碎段；把连续等厚的段落打散成参差；把一两段的结论句删掉，让段落停在事实上。

### D6) 提纲式"挑战与未来展望"专段（原 6）

- **信号**：单独一段写"挑战与机遇并存/未来仍需努力/展望未来/仍有提升空间"。
- **修法**：默认删；真要写"未知"，就写成具体的不确定：哪两条约束卡住、哪一步最难验证，最后落一个冷判断收束。

### D7) "三段式法则"过度使用（原 10）

- **信号**：任何地方都要凑三项：A、B、C；既…又…还…；首先其次最后。
- **修法**：两项优于三项；若确有三层推进，把其中两层合并进长句链，用分号织起来，别列清单。

### D8) 指示性定位收束壳（"X 正卡在这条裂缝里 / X 的难处正在这里"）（原 9.8）

这是 S8"最 X 的地方在于"和 S25③"X 还有一个更麻烦的地方"被禁掉之后，LLM 自动滑向的下一个副本。机制完全相同——给抽象问题指认一个"位置"，让作者像放映员一样手指着说"看，这就是真相所在"——但词面被替换成更口语化的"正/就 + 在这里"或"正卡在 + 空间隐喻里"，伪装成普通陈述句，骗过逐词黑名单。

观察：以下四句话来自不同段落，模型却像约好了一样反复触发同一类句式——

- "中药注射剂正卡在这条裂缝里。"
- "中药注射剂麻烦的地方，正在这里。"
- "中药注射剂的难处正在这里。"
- "血管不认这些词。"（属 S26）

为什么 LLM 会一直触发？两个原因：
1. **段尾收束位的统计偏好**：训练语料里大量评论文章在段落结尾用"X 的地方在于 / 关键就在这里 / 问题正卡在这条线上"做指示性收束，LLM 把这类句子识别为"高质量评论文本"的尾签。
2. **抽象问题需要可视化锚点的语言冲动**：当被讨论的对象（如"中药注射剂的监管处境"）本身没有具体空间位置时，模型会本能地造一个空间隐喻（裂缝/缝隙/夹缝/边界/线/点）来"定位问题"，让读者觉得问题被点穴了。但真正的解释必须给机制（哪条法规、哪个流程、哪种药理），不是给位置。

- **信号（"正/就 + 在/卡在 + 这里/这条/这道"指示性定位）**：
  - `主语 + 正/就/恰好/偏偏/眼下/此刻 + 卡/落/夹/陷/停/堵/挤/吊/悬/绕/绊 + 在 + 这条/这道/这个/那条/那道 + 裂缝/缝/缝隙/夹缝/边界/边/线/点/口/位置/中间/之间 + 里/上/中`。
  - 典型句式："中药注射剂正卡在这条裂缝里""这件事就夹在两条线中间""它正悬在监管的边界上""这场争论一直绕在同一个缝隙里"。
- **信号（"X 的 Y 之处/的地方，正/就在这里"指示性收束）**：
  - `X + 的 + 麻烦/难处/痛点/要害/关键/症结/微妙/吊诡/糟糕/棘手/复杂/特殊/危险/讨厌/微妙 + (之处/的地方/处/点) + ，+ 正/就/恰恰/偏偏 + 在这里/就在这里/正在这里/正卡在这里/正卡在这一点上/在这一点上`。
  - 典型句式："中药注射剂麻烦的地方，正在这里""中药注射剂的难处正在这里""这件事吊诡之处，恰恰在这里""问题真正棘手处，就在这一点上"。
- **信号（"问题/答案/原因 + 就/正 + 在这里"抽象主语指示）**：
  - `问题/答案/原因/事情/关键/分歧/争议 + 就/正/恰恰 + 在这里/在这一点上/在这条线上/在这个缝隙里/在这个边界上`。
  - 典型句式："问题就在这里""答案恰恰在这一点上""分歧正卡在这条线上"。
- **执行标准**：以上三类合并正文清零，逐字引文除外。
- **修法**：
  1) 删掉指示句和空间隐喻，直接铺机制或后果——"中药注射剂正卡在这条裂缝里"换成"中药注射剂没走过西药那套临床试验和药品监督程序，注射用药的安全门槛却按西药同等标准要求，2006 年鱼腥草注射液事件之后这条裂缝一直没补上"。
  2) 把"X 的 Y 之处，正在这里"整句删掉，让后面的具体内容自己说话——读者读到具体的事实，自然知道这就是麻烦所在，不需要作者用手指。
  3) 禁止把"正在这里"换成"就在这里/恰恰在这里/正卡在这一点上"做副词替换逃逸。
  4) 禁止把"裂缝"换成"缝隙/夹缝/边界/边/线/口/缝/位置/中间"做名词替换逃逸——它们是同一个空间隐喻模板。
  5) 禁止把"麻烦的地方"换成"难处/痛点/要害/关键/症结/棘手处/吊诡之处"做名词替换逃逸——它们是同一个收束模板。
- **正误对照**：
  - ❌ "中药注射剂正卡在这条裂缝里。"
  - ✅ "中药注射剂没走过西药那套临床试验程序，却按西药同等标准用于静脉注射；2006 年鱼腥草事件之后这条监管缝隙一直没补上。"
  - ❌ "中药注射剂麻烦的地方，正在这里。"
  - ✅ （直接给出麻烦的具体内容，不预告"这就是麻烦所在"）
  - ❌ "中药注射剂的难处正在这里。"
  - ✅ "中药注射剂这件事难就难在：药材成分复杂、有效物质未必分离干净，进入血液后哪一种是治疗作用、哪一种是副作用，企业自己也说不清。"
  - ❌ "问题正卡在这条线上。"
  - ✅ "问题在文件里写了三年——执行权归省级药监还是国家药监，至今没有定。"
  - ❌ "这件事吊诡之处，就在这里。"
  - ✅ （删整句，让后面的具体事实自己说话）

### D9) 通用积极结论（鸡汤式收尾）（原 24）

- **信号**：未来可期/拭目以待/我们有理由相信/光明前景/这只是开始。
- **修法**：用冷判断、事实或引文收束；若只能写"乐观"，说明前面论证没写够，回去加事实与推演。

### D10) 粗体过度使用（像在做 PPT）（原 14）

- **信号**：正文里频繁 `**加粗**` 强调，或加粗 + 冒号做小标题。
- **修法**：默认去掉所有加粗；重点靠措辞、节奏与落槌，不靠格式。

### D11) 内联标题垂直列表（"小标题：解释"一条条）（原 15）

- **信号**：`**A：** …` `**B：** …` 这种竖排条目，或"概念：定义"连发。
- **修法**：把条目合并为厚段；小标题优先"下沉"为段首转折句（`不过…` / `问题在于…` 这类）。

### D12) 标题中的标题大写（英文化排版）（原 16）

- **信号**：Title Case、全大写、奇怪的英文格式混入中文标题。
- **修法**：统一为中文标题习惯；若标题本就可删，优先删掉让正文自己站住。
