# AI 痕迹检测索引（三层目录 + 快速检查）

先读本文件。详细条目分在四个文件里，按层读取，不要一次通读：

| 层 | 文件 | 什么时候读 | 抓什么 |
|---|---|---|---|
| 叙事层 | `narrative-pass.md` | 只在小说、故事、叙事散文时读，最先读 | 主题被说破、因果链太整齐、靠"想通了"收尾、开头先交代时间地点天气 |
| 篇章层 | `discourse-pass.md` | 所有改写/审阅默认读 | 大纲测试、每段回答什么问题、中段塌陷、位置指纹、段落同构、段尾收束、鸡汤结尾、格式痕迹 |
| 句式层 | `syntax-pass.md` | 篇章层之后，按命中条目读对应章节 | 二分对照、关联词对、极值判断、戏剧化揭露、拟人化否定、温和让步、步骤承接等 28 条 |
| 词表层 | `vocab-pass.md` | 最后读，只清最显眼的 | 拔高词、宣传词、伪口语化引导语、伪学术术语、协作口吻、客服腔、填充短语、标点表情；以及**该放回来的人类语域** |

修补顺序固定为：叙事（如适用）→ 篇章 → 句式 → 词表。深层的问题先修，因为浅层改多少都盖不住深层。

## 通用执行规则

1. **先清单后动手**。修补和重写之前先列完整缺陷清单（每条引原文短语），再逐条修。没有清单直接改写，会把 AI 痕迹改得更显眼。
2. **只抓最要命的**。普通改写只做快速检查；审阅任务列 Top 5–10 条，按"读者是否立刻觉得你在跑提示词"排序。
3. **最小改写**。每个命中做一次补丁：删模板句式、空泛拔高、结构提示符，把信息塞回叙述流里（逗号、分号、插入语接住）；不把单点修补扩散成整段重写。替换和删除多于新增；唯一允许新增的是真实的具体细节。
4. **阈值是识别强度，不是删除配额**。各条目里的"正文清零 / 全文 <= N"标记这条痕迹有多典型；执行时按 SKILL.md 的校准原则：单次出现且读感自然的不算，成簇、连段、明显在替读者宣布结论时才修。修完要落在人类写作的常见区间，不是 AI 的反面。
5. **白名单不动**：逐字引文、对话、原文本来的习惯、正式场合的正式语体、干净的语法、单次出现的破折号或某个词。
6. **回滚检查**。改完通读一遍，出现下面任一症状就退回补丁前版本、只保留必要修补（模板路标、伪引述、硬事实口径、标点硬伤）：
   - 段落明显变薄，信息密度下降。
   - 句子整体变短且均匀，长句链断裂。
   - 作者视角与锋利判断被抹平成中性说明书。

最小改写范式：删"值得注意的是/总体而言/换句话说"等路标词，不重写后半句论证骨架；把"象征着/标志着/体现了"改成一个落地判断或事实短句，不新增段落结构；把"专家认为/研究表明"改成可追溯来源，无来源就降级为限定表述或删除。

## 按任务选择

- 保真改写：篇章层 D1、D5 + 快速检查；命中再查句式层。
- 终稿精修：篇章层 D4、D5（段尾收束、开场短句、等厚）+ 词表层 V9（重复判断词）。
- 审阅评分：叙事（如适用）→ 篇章 → 句式 → 词表，一层一层看，不要一遍读完全部打分。
- 翻译：通常不读本索引；只有译文出现明显讲义腔或协作口吻时读词表层 V10、V12。
- 写新稿：先做篇章层（叙事类先做叙事层）的结构决定，再写，写完只走快速检查。

## 快速检查（默认改写只看这里）

### 篇章层

- 段落是不是被你写碎了？碎段比任何"词汇"都更像 AI。反过来，连续三段厚段也会形成砖墙效应。（D5）
  - 注意区分"碎段"和"节奏短段"：承担承接判断、反讽、转折、收束功能的短段（含一句成段，如"这确实是个很大的黑色幽默。"）是合法的节奏装置，不要回填。只清那些"下面说说/接着看/总之"式路标短段和与上下段语义重复的空转短段。
- 每段第一句连读是不是一份干净的摘要？是就改变信息进入段落的方式，不是换首句。（D1）
- 列举是不是总凑三项、引语是不是总在段尾、每段是不是都有一句总结？（D4、D5）
- 有没有"挑战/机遇/展望未来"这种模板段？删。（D6）
- 结尾是不是在发价值观鸡汤？改成冷判断或事实落点。（D9）
- 有没有"X 正/就 + 卡/落/夹/陷/停 + 在 + 这条/这道/这个 + 裂缝/缝隙/夹缝/边界/边/线/口/位置/中间 + 里/上"或"X 麻烦/难处/痛点/要害/关键/症结的地方/之处，正/就 + 在这里"这类指示性定位收束壳？默认清零——它是 S8"最 X 的地方在于"和 S25③"还有一个更麻烦的地方"被禁后的副本，删掉指示句和空间隐喻，直接铺机制或后果；禁止把"正在这里"换成"就在这里/恰恰在这里/正卡在这一点上"做副词替换逃逸；禁止把"裂缝"换成"缝隙/夹缝/边界/边/线"做名词替换逃逸。（D8）
- 破折号/冒号是不是在当提纲符号用？冒号不设数量硬规定，按实际语义人工判断；若只是路标、提纲或扩音器，就改为逗号、分号或句内解释。（D11、S28）

### 句式层

- 有没有"不是A而是B/不在于A而在于B"这类二分对照壳？默认清零，改成"Ａ确实……，但/而……"或直接给判断。（S15）
- 有没有"把X拆完/说完/看完/理完，再/便/就Y"这类步骤承接过渡句？删掉前半句，直接从新事实或判断起笔。这是最隐蔽的 AI 痕迹之一——逐词黑名单抓不住，必须从句式模板层面拦截。（S2）
- 有没有"一旦……就/只有……才/无论……都/随着……的/正是因为……所以/通过……来"等关联句式堆叠（全文 > 2 即为堆叠）？改为散装条件词或直接铺事实。（S4）
- 有没有"遮羞布/扯下遮羞布/撕下面具/剥开外衣/揭开真面目/戳穿谎言"这类戏剧化揭露修辞？默认清零，改成直接给事实和判断——一组数据比"扯遮羞布"更有杀伤力。（S5）
- 有没有"数字摆得清楚/数字摆得更清楚/数据可以摆出来看/把数据摆出来/再摆一组数据"这类"摆"式数据展示动作？默认清零——删掉"摆"的扩音动作，直接给数字和判断。这是 S5 戏剧化揭露的低戏剧度副本，靠程度副词代替"扯下"。（S6）
- 有没有"最残酷的地方在于/最可怕的地方是/真正可怕的是/讽刺之处在于/更残酷的是"这类极值判断句式（全文 > 1 即为堆叠）？删掉极值框架，直接铺事实和判断——"最残酷的地方在于"不如一组具体数字有杀伤力。（S8）
- 有没有"万能贴纸/万能挡箭牌/万能护身符/万能解药/万能钥匙/万能借口/万能筐"这类"万能 + 具体名词"标签讽刺？默认清零——换成动作或具体功能描述，或直接铺反例。本质同账本/成绩单/清单——把复杂概念包装成可贴的工具。（S11）
- 有没有"骂得最起劲的那批 X/喊得最响的那群 X/跳得最高的那波 X"这类"X 得最 Y 的那批/那波/那群"群体讽刺，或"那批海外华人/那群键盘侠/那拨自媒体"这类"那批 + 群体名"对立化指代？全文合计 `<= 1` 且必须给具体样本——没有具体人/账号/事件就删。（S11）
- 有没有"接这一棒/接力棒/接过 X 的棒/把火炬传给/这一棒传到 X 手里/不必接这一棒"这类代际/历史责任的接力比喻？默认清零——删掉运动器材隐喻，直接铺代际事实或具体后果。（S12）
- 有没有"一整套话术/一整套机制/一整套说辞/一整套逻辑/一整套套路"这类"一整套 + 抽象名词"分析包装定语？默认清零——"一整套"多半是冗余，去掉只剩"这套 X"即可。（S13）
- 有没有"话术在 X 里扎根/套路在 Y 中落地/这套说辞在 Z 里生根/论调在 W 里站住脚"这类抽象事物的拟物化动词？默认清零——换成"流行起来/成了常识/被反复引用"等具体描述。（S13）
- 有没有"X 之所以在 Y 中扎根/X 之所以能在 Y 里流行/X 之所以站住脚"这类长因果分析开段句？全文合计 `<= 1` 且后面必须紧跟可核对机制——拆成短句或直接铺机制。（S13）
- 有没有 `A 是 B`、`所谓 A 即 B`、`A 就是/意味着/可以概括为 B` 这类定义式判断连续出现？超过 3 处或缺少事实支撑就改——把标签句还原成动作、场景、机制或限定条件。（S10）
- 有没有"X 当然有它的 Y / X 当然有它的来处/道理/逻辑/苦衷"这类温和让步打底句？除"紧跟但/而 + 具体事实"的不对称让步外，正文清零，直接铺事实或下断言；禁止把"当然"换成"自然/原本/本来"做变体逃逸。（S25）
- 有没有"X 的麻烦/问题/争议/讨论，原不该/原本不该/本不该 + 被 + 拖进/卷入/牵扯/裹挟/扯进/搬到/写成"这类温和惋惜壳？默认清零——删掉情绪标签和被动句，直接写谁把它拖到了哪里、为什么、有什么后果。（S25）
- 有没有"X 还有一个/另一个 + 更/最/真正 + 麻烦/棘手/讨厌/复杂/严重/微妙/吊诡/难办 + 的地方"或"X 的地方在于/是"这类"地方"包装壳？默认清零——它是 S8"最残酷的地方在于"的低戏剧度副本，删掉"地方"包装，直接给那件更复杂的事本身；禁止把"麻烦的地方"换成"棘手的地方/讨厌的地方/复杂的地方/难办的地方"做变体逃逸。（S25）
- 有没有"血管不认这些词 / 数据不在乎你那一套 / 分子不分中西医 / 历史不会等任何人 / 市场不挑立场 / 算法不讲情面 / 病毒不看护照"这类"无生命主语 + 拟人化否定动词 + 抽象对象"的金句壳？默认清零——它是 S5 戏剧化揭露和 S8 极值判断的拟人化分支，用拟人化否定代替机制说明；改写时直接铺机制（"马兜铃酸的肾毒性作用在分子层面：进入血液后直接结合肾小管上皮细胞 DNA，不因为它来自中药或西药而改变"），禁止把"血管"换成"细胞/分子/数据/历史/算法/市场"做主语替换逃逸，禁止把"不认"换成"不接受/不在乎/不理/不分"做动词替换逃逸。（S26）

### 词表层

- 有没有"值得注意的是/不可否认/总体而言"这种路标？删。（V5、V10）
- 有没有"专家认为/研究表明/业内一致认为"但没有出处？降级或删。（V4）
- 有没有"对研究者而言/历史学家担心"这类代言旁白？若无新增事实就删。（V4）
- 有没有不可追溯的"引号原话/定性标签"？去引号改转述。（V16）
- 形容词是不是多得像广告？删掉一半，先让名词裸奔。（V3）
- 有没有没有增加事实、画面、范围或判断的装饰性状语、补语？删掉“非常认真地”“深刻地揭示”“显得格外”一类空挂修饰；保留改变时间、频率、范围、否定、推测、程度或具体结果的成分。（V3）
- 有没有"拆一拆/拆解/梳理/剖析/聊一聊/盘一盘/捋一捋/盘点一下/划重点/敲黑板/说白了/本质上/归根结底/简单来说/换个角度看"这类 AI 伪口语化高频词？删掉引导语，直接从事实或判断起笔。（V6）
- 有没有"直白/坦率/坦白/赤裸/赤裸裸/无遮拦/明白无误/不加掩饰"这类伪坦率评价词（典型句式"X 说得很直白""答案直白得多""数据说得更直白""备忘录里写得很直白"）？删评价标签，让事实自己说话。（V6）
- 有没有"严谨/严密/严苛/严格/精准/审慎/克制/沉稳/从容"这类伪严谨评价形容词空挂在没有可核对对象的句子上（"严谨地探讨""严密的论证"后没有论证铺开）？一律删，留下名词裸奔。（V6）
- 有没有"舆论场/话语场/公共场域/宏大叙事/官方叙事/摊开来看/底层逻辑/闭环/赛道/抓手/权柄/初登台/面子里子"这类伪学术腔高频词？命中即改——删掉术语外壳，用具体名词或事实句替代。（V7）
- 有没有"口径/出口径/统一口径/定调/定过调/话术/这一套话术/通稿/喉舌"这类政论/媒体研究术语？命中即改——"口径"→"说法"，"定调"→"先表态/带头说"，"话术"→"说辞"，"通稿"→"统一文本"。配套警惕"X 研究部和 Y 咨询部"这类机构串联做权威铺垫——要么给具体原话，要么删一个机构。（V8）
- 有没有"让我们/接下来我们将/希望这能帮助你/截至我的知识/作为 AI"这类协作口吻或免责声明？删。（V12、V13）
- 改完之后，原文本来有的口语连接词、语气词、直接否定、重复的"说"有没有被磨掉？放回来。（V17）

## 审阅模式输出模板（仅当用户要求"审阅/检查/评分"时）

输出顺序固定为：

1. **风格一致性结论（1 段）**：是否仍像原作者，而不是"通用除味文"。
2. **AI 痕迹 Top 命中（5–10 条）**：每条三段式，尽量短。
   - 命中项：`编号 名称`（如 `S15 二分对照壳`）
   - 触发片段：引用不超过 20 字；没有引文的不列
   - 修法：一句话（不规定特定文风，保持原文语感即可）
3. （可选）**风险提示**：如果"除味"导致段落变薄、句子变短、语体变平，就必须回滚。
